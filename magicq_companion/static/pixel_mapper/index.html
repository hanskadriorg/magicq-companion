Controls

  • Scroll wheel or + / - — zoom
  • Arrow keys — pan view
  • Middle-drag or Space+drag — pan with mouse
  • Drag on empty grid — box-select fixtures
  • Head list — Shift/Ctrl+click for multi-select
  • A select all · double A select none
  • E then H / V — even spacing horizontal / vertical
  • Click fixture — rotate 45° (single selection)
  • Double-click — edit head number
  • F or Focus button — fit selected in view
  • Green dot — pixel 1 (LED start)
